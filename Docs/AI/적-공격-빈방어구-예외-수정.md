# 적 공격 시 빈 방어구 슬롯 예외 수정

## 확인된 원인

Unity 콘솔의 NullReferenceException 2건 모두 CombatManager.AttackTurn의 기존 227행을 가리켰다. 적이 플레이어에게 피해를 준 뒤 armorItem 배열을 순회하며 빈 슬롯에도 item.Use(player)를 호출했다. 네 부위 중 미착용 부위가 하나라도 있으면 예외가 발생하여 공격 로그/후속 턴 진행이 중단될 수 있었다.

## 수정

- 미착용 슬롯은 정상 상태로 취급하여 건너뛰고 장착 방어구만 내구도를 감소시킨다.
- 장비 컨테이너 또는 방어구 배열이 없는 경우에도 피해 처리는 유지한다.
- 플레이어 무기 처리에도 장비 컨테이너 유무를 확인한다.
- 명중/피해 계산과 기존 방어구 전체 내구도 감소 정책은 변경하지 않았다.

## 검증

사용자 승인 후 기존 Play Mode를 저장 없이 종료했다. 수정 후 재진입하지 않았다.

CombatAttackValidation: Edit Mode 11개 통과. 실제 AttackTurn 코루틴을 공격 결과 로그 출력 직전까지 실행하여 네 슬롯 미착용, 일부 장착, 배열/컨테이너 누락, 플레이어·적 공격 3회씩 교대 호출, 내구도 감소를 확인했다. 임시 캐릭터·장비만 사용하고 검사 후 제거했다.

이는 실제 공격 처리 경로 검사이며 전체 CombatLoopStart의 클릭 입력 대기, 사망·보상·노드 이동까지 실행한 Play Mode 검증은 아니다. 실제 세이브와 씬 에셋은 이번 수정에서 변경하지 않았다.
