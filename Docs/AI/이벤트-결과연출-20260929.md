# 이벤트 결과 로그와 중앙 문구

## 적용 내용

- 현재 Execute의 반환 타입은 RewardResult이다. message는 중앙 본문이 아닌 EventResultLog로 전달한다.
- GameWindow의 MainUIGroup/SubUIGroup/EventLogArea에 로그 영역을 연결했다. 기존 UICanvas/SubUIGroup은 이동하지 않았다.
- 로그는 흰색 36 크기, 배경 없이 선택지 위쪽 오른쪽 정렬로 표시한다. 줄바꿈으로 분리하며 빈 줄은 생략한다.
- 첫 줄부터 순차적으로 0.2초 간격으로 표시한다. 새 줄이 나오면 앞선 줄은 위로 밀리며, 각 줄은 자신의 표시 시점부터 서서히 투명해져 3초에 제거된다. 시간 배율과 무관한 시간을 사용한다.
- 중앙 EventResultText는 ResultText를 TypeTextCoroutine으로 표시하고 WaitForClick.WaitClick으로 다음 클릭을 기다린다. 선택 버튼 클릭이나 타이핑 중 유지한 터치를 확인 입력으로 재사용하지 않는다.
- 결과를 기다리는 동안 선택지를 숨겨 중복 실행을 방지한다. 확인 버튼은 생성하지 않는다.
- 성공 후 NextNodeID가 있으면 결과 확인 뒤 이동한다. 없으면 현재 이벤트의 선택지를 다시 표시한다. ExitNodeID 자동 대체는 하지 않는다.
- 실행 실패는 로그로 알리고 선택지로 돌아온다. 성공용 ResultText를 표시하거나 다음 노드로 이동하지 않는다.
- 화면 전환 또는 비활성화 시 결과 코루틴을 취소한다. 로그는 EventUI 밖에 있어 일반 노드 이동 후에도 남은 수명 동안 표시할 수 있다.

## 시트 사용법

기존 Google 스프레드시트 EventChoiceData의 W3에 ResultText 헤더를 추가했다. 문자열 열이며 기존 데이터 55행은 빈 값으로 유지했다. 다른 선택지 데이터와 조건은 변경하지 않았다.

1. 원하는 선택지 행의 W열에 결과 서술을 작성한다. 예: `당신은 소녀에게 음식을 건넸다.\n소녀가 고개를 숙여 감사한다.`
2. Unity에서 Tools > Validate Remote Game Data (No Changes)를 실행한다.
3. Tools > Update All Game Data를 실행하고 미리보기 후 적용한다.
4. 해당 선택지를 실행하면 보상 수치는 로그로, 작성한 서술은 중앙에 표시된다.

ResultText가 비어 있으면 중앙 문구와 클릭 대기를 생략한다. 실제 줄바꿈과 문자열 `\n` 모두 가져오기에서 처리한다. 새 임포터는 ResultText 헤더가 필요하다. 기존 SO의 비어 있는 resultText는 정상이다.

## 검증 결과

- 2026-09-29 Unity 2021.3.45f2, Edit Mode에서 EventResultPresentationValidation 12개 통과.
- 검사 항목: 줄 간격, 문구/폰트/색상, 클릭 비차단, 위로 쌓기, 투명도, 개별 3초 수명, 정리 메서드, ResultText 매핑/줄바꿈/빈 값.
- 비활성화 정리는 Edit Mode에서 콜백을 직접 호출한 검사다. 실제 Play Mode 수명주기 검사는 아니다.
- GameWindow의 로그/중앙 텍스트 참조 확인. 누락 스크립트 0개. 읽기 확인 후 임시로 연 씬은 저장 없이 닫았다.
- 원격 6개 시트 검사 통과: 아이템 11, 적 7, 노드 29, 이벤트 17, 선택지 55, 보상 행 26. 이 검사는 에셋을 덮어쓰지 않는다.
- 컴파일 완료 상태 및 콘솔 오류/경고 0개 확인.
- 기존 NodeChoiceUIValidation은 앞선 실행에서 'Event 완료 후 신규 버튼 표시' 검사에 실패했다. 조건 미충족 선택지를 숨기도록 한 사용자 변경과 해당 검사 기대가 다르다. 이번 결과 연출 작업에서는 그 동작이나 기존 테스트를 임의로 변경하지 않았다.
- Play Mode 클릭, 모바일 터치, 실제 해상도에서의 문구 겹침 및 Android 빌드는 미검증이다.

## 수동 확인

- 짧은 ResultText가 있는 선택지를 실행해 중앙 타이핑 완료 전 이동하지 않는지 확인한다.
- 화면을 누른 채 유지해도 바로 넘어가지 않고, 손을 뗀 뒤 새 클릭에 이동하는지 확인한다.
- NextNodeID가 없는 선택지는 확인 뒤 원래 선택지로 돌아오는지 확인한다.
- 여러 줄 보상은 0.2초 간격으로 뜨고 각 줄이 3초 후 사라지는지 확인한다.
- 긴 한국어 결과 및 보상 문구를 실제 Game View 해상도에서 확인한다.

## 변경 보존

기존 미커밋 선택지 숨김 처리, 버튼 스타일, 게임/보상/인벤토리 수정은 유지했다. 작업 중 생성된 TMP 동적 폰트 에셋 변경도 임의로 되돌리지 않았다. 커밋과 푸시는 실행하지 않았다.
