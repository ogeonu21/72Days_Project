# 개발 워크플로와 Linear 등록용 백로그

> 작성일: 2026-09-08  
> 등록 방법: Linear 프로젝트 **Days Stabilization & Expansion**을 만들고 아래 에픽과 이슈를 등록한다. `WAR-*`는 제안 ID다.

## 전체 워크플로

```text
보안 기준선
  → 저장 신뢰성
    → 테스트 기준선
      → 세션·진행 흐름 리팩터링
        → UI·전투 통합/분리
          → 콘텐츠 파이프라인·플랫폼 검증
            → 신규 게임플레이 확장
```

상태 흐름: `Backlog` → `Ready` → `In Progress` → `In Review` → `Verified` → `Done`

- Ready: 수용 기준, 영향 씬/콘텐츠, 선행 의존성이 적혀 있음.
- Done: 코드 리뷰, 관련 테스트 통과, Unity Console 신규 오류 없음, 요구된 Play Mode/빌드 검증 기록 완료.
