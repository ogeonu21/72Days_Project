# 전투 선택지 크기·간격 통일

- 기준: GameWindow의 Story/Event 선택지 템플릿. 기준 화면에서 840×100, 중심 간격 160 → 버튼 사이 빈 간격 60.
- 기존 동적 선택지는 높이 95·간격 12이고 부모 패널 너비까지 확장되었다.
- ChoiceUIRouter의 공통 레이아웃을 수정: 템플릿 실제 너비 사용, 높이 최소 100, 간격 60, 상단 중앙 정렬, 가로 강제 확장 해제.
- Combat의 아이템 사용·도주뿐 아니라 소모품 목록·뒤로 및 공통 라우터를 사용하는 Event 동적 선택지도 같은 규격을 사용한다.
- 부위별 공격 버튼, 전투 판정, 텍스트와 선택지의 세로 영역 분리는 변경하지 않았다.
- Edit Mode에서 실제 Story 템플릿으로 Combat 선택지 두 개를 생성한 격리 검사: 원본 840×100, 생성 버튼 840×100, 빈 간격 60 확인.
- 컴파일 Console 오류 0개. Play Mode는 실행하지 않았고 씬/세이브는 저장하지 않았다.
