# 클릭 대기 입력 누락 보완

## 신고 및 확인

- Unity Game 창의 MainStoryNode에서 클릭해도 진행하지 않는 현상.
- 조사 시 Unity는 Edit Mode였으므로 해당 실행 상태를 직접 재현하지 못했다.
- Console 오류 0개. Main_01 → Main_02, Main_02 → Main_03, Proto_Start → Proto_Supply 참조 정상.
- 기존 WaitForClick에서 접촉이 계속 보고되는 동안 새 입력이 와도 대기를 유지하는 것을 합성 입력으로 재현했다.
- 이것이 신고된 Game 창 정지의 유일한 원인인지는 아직 확인되지 않았다.

## 수정

- 전체 접촉이 사라지는 프레임을 기다리던 선행 루프 제거.
- 진입 프레임은 무시하고 이후 새 MouseDown/TouchPhase.Began만 수락.
- 따라서 기존 누름 유지나 손 떼기만으로 자동 진행하지 않는다.
- Unity Editor의 마우스 입력은 모바일 환경 여부와 관계없이 허용한다.
- 모바일 빌드에서는 합성 마우스를 제외하고 새 터치를 사용한다.
- 다른 손가락이 눌린 채 새 손가락으로 탭하는 것도 새 확인 입력으로 인정한다.
- 노드 데이터, 타이핑 속도, 저장 동작은 변경하지 않았다.

## 검증

- WaitForClickValidation: Edit Mode 합성 입력 23개 통과.
- Unity Console 오류 0개.
- Play Mode·실제 마우스·모바일 실기기는 미검증. 실제 저장 파일은 변경하지 않음.
- 수동 확인: Game 창에서 MainStoryNode 본문이 끝난 뒤 클릭 → 다음 노드 이동. 길게 누른 채 다음 대기에 진입하면 자동 통과하지 않고 새 클릭을 기다려야 함.
- 여전히 정지한다면 멈춘 상태를 유지하고 노드 이름·본문 완료 여부를 확인해야 한다. 대기 도달 전 타이핑 정지, UI 비활성화, 노드 이동 실패는 별도 원인일 수 있다.
