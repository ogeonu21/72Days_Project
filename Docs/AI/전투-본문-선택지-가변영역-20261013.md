# 전투 본문·선택지 가변 영역

- CombatUIRouter에서 하단 공간의 45%를 선택지에 고정 배분하던 계산을 제거했다.
- 본문의 현재 문자열과 표시 폭을 사용해 TMP 권장 높이를 측정하고, 본문에 필요한 높이만 배분한다.
- 남는 공간은 선택지 패널에 배분한다. 본문이 없으면 하단 공간 전체를 선택지에 배분한다.
- 기존 버튼 크기·간격은 유지하며, 긴 목록은 기존 RectMask2D/ScrollRect 안에서 스크롤한다.
- 긴 본문에서도 버튼 하나와 스크롤 안쪽 여백(124), 본문과의 간격(16)을 확보한다. 본문은 기존 자동 글자 크기/마스킹 설정을 유지한다.
- 문자열 또는 부모 영역 크기가 바뀌면 재계산한다. 부위별 공격 영역을 침범하지 않도록 상단 경계를 제한한다.
- Edit Mode 임시 UI(1080×1200, 공격 영역 500) 검사: 짧은 본문 선택지 높이 598.37, 긴 본문 124, 빈 본문 676. 상단/하단 경계 검사 통과.
- Console 오류 0개. 실제 Play Mode·모바일 실기기 검증은 수행하지 않았다.
- 이번 수정 범위는 CombatUI 하단 배분이며 Story/Event의 본문 영역 배치는 변경하지 않았다.
