# Unity 프로젝트 헬스 리포트

> 분석일: 2026-09-08  
> 기준 커밋: `91eb3d9aeaebf292be630e198d648bdb90dcaf05`  
> 범위: 읽기 전용 설계·유지보수성·저장·UI·빌드·워크플로 점검

## 종합 평가

노드 콘텐츠, 전투, 이벤트, UI가 갖춰진 프로토타입이다. 다만 전역 매니저, 씬 Inspector 연결, 정적 이벤트, ScriptableObject가 **변경 가능한 게임 상태를 나누어 소유**한다. 기능이 늘어날수록 저장·분기 콘텐츠·UI의 변경 비용과 결함 위험이 커진다.

## 점검 범위와 한계

- 확인: 1차 런타임/에디터 코드, 패키지, 빌드 씬, Android 설정, Git 상태, Unity 콘솔, 활성 `MainWindow` 계층.
- 미실행: Play Mode, Android 빌드/설치, 성능 측정, `GameWindow` 전체 Inspector 연결, 테스트 실행, 릴리스 서명.

## 상세 평가와 조치

### H-001 — 서명 파일과 민감 설정이 추적됨

- 근거: `Keystore/kguWarLike.keystore`, `ProjectSettings/ProjectSettings.asset`가 Git 추적 대상이다.
- 영향: 저장소 접근자가 앱 서명 또는 민감 설정을 악용할 수 있으며, 파일 삭제 후에도 Git 이력에 남는다.
- 조치: 자격 증명을 즉시 회전하고, 비밀 저장소/로컬 무시 설정으로 이동한 뒤 협업자와 이력 정리 방식을 합의한다.
- 검증: 새 클론에 비밀 파일이 없고 주입형 설정으로 Android 개발 빌드가 가능해야 한다.

### H-002 — 안정적인 저장 계약이 없음

- 근거: `SaveManager`는 `JsonUtility`와 Base64로 `Node`, `BaseItem` 참조를 포함한 `SaveData`를 저장한다. `ItemData`에는 `[Serializable]`이 없고, 장비는 `PlayerData` 저장/복원 경로에서 완결되지 않는다. 버전·임시 파일·마이그레이션이 없다.
- 영향: 콘텐츠 변경이나 쓰기 중단에서 진행 데이터가 깨지거나 유실될 수 있다. Base64는 보안 기능이 아니다.
- 조치: 노드/아이템/장비를 안정적인 ID로 저장하는 `SaveGameV1` DTO, 스키마 버전, 원자적 교체, 오류 복구, 마이그레이션 경계를 만든다.
- 검증: 새 게임 → 진행 → 저장 → 재실행에서 노드/HP/화폐/인벤토리/장비/선악 수치를 확인하고, 손상·구 버전 파일도 테스트한다.

### H-003 — 명시적인 세션 조립 지점이 없음

- 근거: `SingleTon<T>.Instance`가 없는 매니저를 자동 생성한다. `GameManager`가 씬 전환과 화폐·인벤토리·캐릭터·노드를 직접 획득한다.
- 영향: Inspector 연결 누락이 임시 매니저로 숨겨지고, 씬 진입 순서에 따라 동작이 달라질 수 있다.
- 조치: 영속 `GameSession` 조립 루트를 두고 필수 씬 서비스를 명시 등록한다. 게임플레이 매니저 자동 생성은 제거한다.
- 검증: Main → New → Main → Load 반복에서 중복 객체·구독 누수·null 연결이 없어야 한다.

### H-004 — 선택 UI를 공통 프리젠터로 통합해야 함

- 근거: `StoryUIController`와 `EventUIController`가 버튼 초기화, 본문 표시, 라벨 설정, 리스너 추가를 중복 수행한다.
- 조치: 선택 목록과 `Action<Choice>` 콜백을 받는 `ChoiceListPresenter`를 추출한다. 기존 컨트롤러는 얇은 노드 어댑터로 유지한다.

### H-005 — 이벤트/매니저 경계가 중복·미완성

- 근거: `CombatEvent`는 `GameEvent`와 중복되고 호출처가 없다. `StoryManager`는 동작이 없고 `EventManager.EventNodeStart`는 비어 있다. `UIManager`는 화면 전환·HUD·인벤토리·모달·적 표시를 모두 맡는다.
- 조치: 빈 추상화는 제거하거나 완료한다. `UIManager`는 화면 라우터·HUD·인벤토리·모달 프리젠터로 분리한다.

### H-006 — Google iOS Resolver 로드 오류

- 근거: Unity Console에 `Google.IOSResolver.dll`을 오류 때문에 로드하지 못한다는 메시지가 있다.
- 조치: Unity 2021.3.45f2와 의도된 플랫폼에 맞는 External Dependency Manager/Google Play Games 호환성을 점검한다. Android Gradle 기존 변경을 검토하기 전 패키지를 바꾸지 않는다.

### H-007 — 회귀 방지 장치 없음

- 근거: Test Framework는 설치됐지만 1차 테스트 코드·테스트 asmdef·CI가 없다.
- 조치: 저장 DTO와 전투 규칙 EditMode 테스트, 시작·새 게임·불러오기·노드 전환 PlayMode 스모크 테스트, 머지 전 CI 실행을 추가한다.

### H-008 — 데이터 임포트가 파괴적이고 동기적임

- 근거: `DataImporter`가 네트워크 응답을 동기 대기하며 `AssetDatabase.DeleteAsset`를 호출할 수 있다.
- 조치: 가져오기 → 파싱 → 검증 → 미리보기 → 적용으로 분리하고, 오류 데이터에서는 자산을 바꾸지 않는다.

## 건강한 부분

- 노드·적·아이템·이벤트가 ScriptableObject로 콘텐츠화되어 있다.
- 에디터 코드는 `Assets/Editor`에 분리됐고 런타임 코드에 `UnityEditor` 의존성이 없다.
- 전투 진행이 코루틴 기반이며 빌드 씬 순서와 Android 설정이 명시적이다.
- Unity 에디터는 연결·대기 상태이고, 읽어온 콘솔에는 1차 C# 컴파일 오류가 없었다.
