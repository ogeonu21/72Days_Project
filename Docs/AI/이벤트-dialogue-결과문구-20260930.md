# 선택지 실행 후 dialogue 결과 문구

## 데이터 구분

| 데이터 | 용도 |
| --- | --- |
| NodeData.NodeMessage | 이벤트 진입 시 본문 |
| EventChoiceData.Text | 선택 전 버튼 문구 |
| EventChoiceData.ResultText (W열) | 실행 성공 후 dialogue에 표시할 서술 |
| RewardData | 실제 능력치·아이템·골드 보상 |

NodeData.EventDefinitionID → EventDefinition.options → 선택지별 resultText 연결을 유지한다. Node에 결과 문구를 중복 저장하지 않는다. DataImporter가 ResultText를 EventOption.resultText로 가져온다.

## 적용

- 실제 이벤트 선택지 37개에 결과 문구를 작성하고 시트와 SO 양쪽에 반영했다. 개발용 이동 메뉴 18개는 빈 문구를 유지했다.
- 힘 +1: `운동을 통해 힘이 1만큼 증가하였다.`
- Training_01의 기존 힘 +10 보상은 변경하지 않았다. 이 선택지의 문구는 힘이 10만큼 증가했다고 표시한다.
- 확률 아이템, 최대 체력 제한, 보유 골드 이하 손실은 고정 서술로 실제 획득량을 단정하지 않는다. 실제 수치는 별도 로그를 확인한다.
- 실행 성공 → 기존 dialogue에 결과 타이핑 → 새 클릭 대기 → NextNodeID 이동 순서다. 다음 노드가 없으면 결과 문구를 유지하고 선택지를 다시 표시한다.
- ResultText가 비어 있으면 결과 타이핑·클릭 대기는 생략한다. 실패하면 성공 서술은 출력하지 않는다.
- 선택지 조건, 비용, 보상 수치, 노드 연결은 이번 문구 반영에서 변경하지 않았다.

## 확인

- 작성한 37개 시트 셀 재조회 일치.
- Unity 에셋 37개 선택지 반영, 콘텐츠 연결 오류 0개.
- 원격 6개 시트 검증 통과: 아이템 11, 적 7, 노드 29, 이벤트 17, 선택지 55, 보상 행 26.
- Play Mode 실제 클릭 및 화면 가독성 검사는 실행하지 않았다.
- 별도 기존 로그 검사에서 `로그 내용과 스타일` 항목이 실패했다. 직접 확인 결과 폰트 36·흰색은 정상이지만 여러 줄 입력이 한 로그에 그대로 들어간다. 이번 dialogue 데이터 변경과 별개의 로그 줄 분리 문제로 남아 있으며 전체 회귀 검사 통과로 보고하지 않는다.

이후 문구 수정은 시트 W열에서 한 뒤 Tools > Update All Game Data로 가져오면 된다. 이번 문구는 이미 에셋에 적용했으므로 별도 수동 가져오기가 필요 없다.
