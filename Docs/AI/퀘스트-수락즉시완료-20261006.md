# 퀘스트 수락 직후 완료 검사

## 확인한 원인

기존 EventManager는 AcceptQuest 선택지를 실행하면 acceptedQuests에만 기록했다. 완료 조건은 CompleteQuest 선택지를 별도로 클릭할 때 검사했으며, 이미 조건을 충족한 상태로 수락해도 자동 완료로 이어지는 경로가 없었다.

조건 판정기는 아이템 ID별 수량 합산, 보유 골드·비용, 기본 STR/DEX/CON, 성향, 선행 퀘스트 상태를 모두 AND로 검사한다. 완료 처리는 수락 이력이 있고 아직 완료되지 않은 퀘스트만 허용한다.

## 수정 동작

1. 수락 선택지의 조건·확률·보상 처리를 통과하면 수락 상태를 기록한다.
2. 같은 EventDefinition에서 Action=CompleteQuest이고 QuestID가 같은 선택지를 찾는다.
3. 표시와 동일한 EventChoiceEvaluator로 완료 조건을 재검사한다. 처리 중 잠금은 유지한다.
4. 조건에 맞는 완료 선택지를 하나 실행한다. 기존 확률·비용·보상 검증을 그대로 따른다.
5. 완료 보상 지급까지 성공해야 완료 상태와 수령 기록을 남긴다. 결과 로그에 완료 안내를 추가하고, 중앙 본문은 완료 선택지의 ResultText를 사용한다. 문구가 비어 있으면 퀘스트 완료 안내를 대신 표시한다.
6. 문구 출력 후 클릭하면 완료 선택지의 NextNodeID로 이동한다. 연결이 없으면 현재 이벤트에서 갱신된 선택지를 보여준다.
7. 수락과 자동 완료를 합쳐 저장 요청은 한 번만 발생한다.

조건 미달이면 수락만 유지한다. 나중에 조건을 채운 뒤 완료 선택지를 선택할 수 있다. 가방 공간·소지금 상한 등의 지급 오류가 발생하면 완료 상태나 완료 보상을 기록하지 않으므로 다시 시도할 수 있다.

## 데이터 작성 규칙

새 시트 열이나 SO 필드는 추가하지 않았다. 같은 이벤트 안에 수락·완료 두 선택지를 두고 QuestID를 동일하게 설정한다. 완료 요구 조건과 보상은 CompleteQuest 행에 작성한다. 두 선택지 모두 Repeatable=false를 유지한다.

- 퀘스트 완료를 확정 처리하려면 완료 선택지의 SuccessProbability=1로 둔다.
- 확률이 1 미만이면 기존 단발 선택지의 확률 실패 규칙이 적용된다. 퀘스트의 완료 재시도를 의도한다면 확률을 1로 설정하는 것이 현재 구조에 맞는다.
- 자동 탐색은 같은 EventDefinition 내 동일 QuestID에 한정한다. 완료 NPC가 다른 이벤트에 있다면 해당 이벤트에서 수동 완료한다.
- 완료 후보가 여러 개라면 데이터 순서상 조건을 충족하는 첫 선택지만 시도한다.
- requiredItem과 requiredGold는 보유 확인이다. 아이템은 납품·소비하지 않고, 골드 차감은 goldCost/goldLoss로 별도 설정한다.
- 스탯 조건은 장비 포함 최종 수치가 아니라 player.baseStats를 검사한다.

## 현재 에셋에서 확인한 조건

| 이벤트 / 퀘스트 | 완료 조건 |
| --- | --- |
| Demo_Quest / Demo_Q01 | Potion_01 1개 보유 |
| QA_QuestEvent / QA_Preparation | Proto_Potion 2개, 골드 50 이상, STR/DEX/CON 각각 1 이상, 성향 1 이상 |

Potion_01과 Proto_Potion은 서로 다른 아이템 ID다. 이름이 비슷해도 대체해서 인정하지 않는다. 두 퀘스트의 완료 확률은 확인 시점 기준 1이다.

## 변경과 검증

- EventManager: 일반 선택지 실행을 공통 처리로 분리하고 수락 직후 완료 검사 추가.
- RewardResult.completedQuestOption: UI에 실제 완료 문구·이동 정보를 전달하는 런타임 필드. 저장 형식 변경 없음.
- EventUIRouter: 자동 완료된 선택지의 문구·이동 대상 사용.
- QuestCompletionValidation: 임시 객체와 격리된 이벤트·싱글턴으로 검사. 실제 저장 구독자는 호출하지 않고 원복.
- 퀘스트 검사 22개, 기존 선택지 조건 검사 34개, 이벤트 확률 검사 14개 통과. Unity Console 오류 0개.
- 아이템/골드/각 스탯/성향 부족, 중복 보상, 가방 부족·소지금 상한, 재시도, 완료 기록 직렬화 왕복 확인.
- Play Mode에서 실제 퀘스트 화면·클릭·노드 이동은 실행하지 않았다. 실제 세이브·씬·시트 데이터는 수정하지 않았다.
