# 선택지가 표시될 때만 본문 영역 조정

- CombatUIRouter가 본문 원래 앵커·여백·폰트 크기를 최초 연결 때 보관한다.
- 선택지 표시 중에만 가변 영역을 적용한다. 숨겨진 패널의 크기 변경 콜백은 무시한다.
- HideChoices를 가상 메서드로 바꾸고 전투 라우터에서 숨길 때 원래 본문 영역을 즉시 복원한다. 행동 제출·공격 처리·비활성화에도 같은 경로를 사용한다.
- 강제 Auto Size(24~48) 설정을 제거하고 연결 당시 폰트 크기를 고정한다.
- Edit Mode 임시 UI 검증: 표시 중 영역 조정, 숨김 후 복원, 숨김 상태 재배치 무시, 폰트 48 유지 통과.
- 실제 Play Mode 검증은 수행하지 않았다. 씬·저장 데이터 변경 없음.
