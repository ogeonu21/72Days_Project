# UTF-8 인코딩 통일

2026-09-09 작업 기록.

## 변경

- CP949로 저장된 프로젝트 C# 파일 33개를 UTF-8(BOM 없음)로 변환했다.
- 기존 UTF-8/ASCII 파일은 유지했다. ASCII는 UTF-8과 호환된다.
- 주석, 한글 식별자, 문자열, 코드 동작과 GUID는 변경하지 않았다.
- `.editorconfig`에 UTF-8 저장 규칙을 추가했다.
- 읽기 전용 검사 도구 `Tools/Check-TextEncoding.ps1`을 추가했다.
- Library, Temp, Builds 등의 생성물과 바이너리 파일은 텍스트 변환 대상에서 제외했다.

## 검증

- 변환 전 CP949 디코딩/재인코딩 결과가 원본 바이트와 일치했다.
- 변환 후 Git HEAD의 CP949 원본과 Unicode 텍스트를 비교하여 33/33 일치를 확인했다. Git의 LF/작업 폴더 CRLF 차이는 비교 시 정규화했다.
- 소스·문서·설정·씬·프리팹·메타·셰이더 등 저장소 텍스트를 엄격한 UTF-8로 검사했다. 잘못된 바이트 시퀀스와 대체문자 U+FFFD가 없었다.
- Unity 강제 리프레시 및 재컴파일 후 Console 오류/경고 0건.
- 사용자가 한글 표시 복구를 확인했다.
- 기존 `ProjectSettings/TimeManager.asset` 변경은 건드리지 않았다.

## 다시 검사하기

프로젝트 루트의 PowerShell에서 `./Tools/Check-TextEncoding.ps1`을 실행한다.
검사는 파일을 수정하지 않으며 UTF-8이 아닌 파일이나 손실 대체문자가 있으면 실패한다.
이미 잘못된 문자가 정상 Unicode로 저장된 경우까지 의미적으로 판별하는 도구는 아니므로, 이상한 문구가 발견되면 Git 원본과 대조한다.
