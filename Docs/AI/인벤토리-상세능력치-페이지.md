# 인벤토리 상세 능력치 페이지

## 사용 방법

InventoryUI의 STR·DEX·CON 영역(Status_UIGroup)을 누르면 상세 페이지가 열린다. 닫기 버튼 또는 Escape로 상세 페이지만 닫는다. 인벤토리를 닫을 때 상세 페이지도 초기화된다. 상세 페이지 자체는 게임 시간 배율을 변경하지 않는다.

## 표시 정보

- 현재 HP / 최대 HP 숫자와 체력바.
- STR, DEX, CON.
- 최종 공격력과 기본·능력치 기여분, 장비 공격력, 기타 보정(버프·디버프 등).
- 최종 회피율과 능력치·방어구·장신구·기타 보정. 현재 계산식의 상한 70% 안내.
- DEX 기반 명중 보정. 현재 장비에는 명중 보정이 없으며 최종 적중률은 공격 부위와 적 회피율에 의해 달라짐을 명시.
- 최종 사거리와 무기·기타 보정.

## 구현

- Player.GetEquipmentTuningStats로 장비 합산을 공유한다. 기존 UpdateTuningStats의 계산 결과는 유지한다.
- PlayerStatsDetailsUI는 현재 플레이어의 StatsChanged를 구독하고 비활성화 시 해제한다.
- InventoryUI는 플레이어 교체와 상세 창 열기, Escape 우선순위를 연결한다.
- InventoryUISetup.InstallStatsDetails는 기존 인벤토리를 재설치하지 않고 상세 페이지만 추가한다. GameWindow 씬에 설치 완료. 수동 Inspector 연결은 필요 없다.
- 기존 아이템 사용·장착 후 CloseDetails를 호출하는 사용자 수정은 유지했다.
- 한글 표시 과정에서 Inventory Dynamic SDF 폰트의 동적 글리프 캐시도 갱신되었다.

## 검증

- Unity 2021.3.45f2 컴파일 후 Edit Mode 상세 UI 검사 12개 통과.
- 기존 Character/Save 26개, Item/Save 51개 통과. 실제 저장 파일 변경 없음.
- 씬의 기존 오브젝트/컴포넌트 ID 삭제 없음 확인.
- 콘솔에 MCP WebSocket 연결 경고 1건. 게임 코드 컴파일 오류는 관찰되지 않았다.
- 사용자 요청에 따라 Play Mode는 실행하지 않았다. 실제 클릭·Escape 입력, 화면 육안 확인 및 Android 검증은 미실시.
