# 성향 아이콘 픽셀 재제작

- 게임의 실제 전투 UI 캡처를 스타일 참조로 사용하여 내장 이미지 생성 도구로 제작.
- 5단계 저울의 방향·의미 유지. 가는 선을 굵게 바꾸고 주홍·청록색 면적과 대비를 확대.
- 최종 PNG: 각각 80×80 RGBA. `final/tendency-1.png`부터 `tendency-5.png` 순서.
- 기존 `Assets/Resources/UI/Tendency/`의 동일 이름 PNG 5개를 교체. 기존 meta는 유지.
- 이전 72×72 원본은 `../Tendency-20261007/processed/`에 보존되어 복구 가능.
- 스킬 처리기의 배경 제거·추출·QC 사용. 완전한 저울 실루엣을 재배치하여 분할 경계 잘림을 방지.
- 축소는 nearest-neighbor 방식으로 처리해 픽셀 경계를 보존. 그림을 코드로 그리지 않음.
- 최종 QC: 5개 유효, 빈 프레임·가장자리 접촉·잘린 배치 0개.
- 프롬프트: `prompt-used.txt`. 원본: `raw-original.png`. 재처리: `process_pixel.py`.
- 이번 작업은 이미지 교체만 수행. 글자 크기·씬 배치·오브젝트 이름 연결 및 런타임 UI 크기는 변경하지 않음.
