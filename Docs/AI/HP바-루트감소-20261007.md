# HP바 루트 감소 애니메이션

플레이어와 적의 Character.hpSlider에 HealthBarAnimation을 자동 연결한다. 실제 HP, HP 숫자, 사망 판정은 즉시 갱신하고 바의 감소 표시만 0.6초 동안 보간한다.

진행률 t = clamp(경과 시간 / 감소 시간, 0, 1)

표시값 = 시작값 + (목표값 - 시작값) × √t

시간이 25% 경과하면 감소량의 50%를 반영한다. 처음 빠르게 줄고 뒤로 갈수록 느려지며, 종료 시 정확한 목표값으로 맞춘다. 끝의 기울기가 0이 되는 일반적인 ease-out과는 다른 실제 제곱근 보간이다.

- 연속 피해: 현재 표시 위치에서 새 목표로 이어서 감소.
- 같은 HP로 스탯 알림이 반복되어도 애니메이션을 재시작하지 않음.
- 회복·최초 표시·Edit Mode 표시: 즉시 반영.
- 비활성화: 목표값으로 정리해 재활성화 시 이전 피해 연출이 남지 않음.
- 시간 배율과 독립적인 unscaledDeltaTime 사용.
- 소요 시간은 HealthBarAnimation의 decreaseDuration(기본 0.6초)으로 조절. 기본 사용은 별도 Inspector 연결 불필요.
- 상세 능력치 페이지의 별도 HP바는 이번 변경 대상이 아니다.

검증: Edit Mode 검사로 최초 표시, 루트 곡선, 중복 알림, 연속 피해, 사망, 회복, 초기화, 숨김, 보간 범위를 확인한다. 실제 Play Mode 및 모바일 기기 검증은 수행하지 않았다. 씬·저장 형식과 사용자 효과 수치 변경은 유지했다.
