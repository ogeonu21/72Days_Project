# 성향 저울 아이콘 적용

## 표시 규칙

| 성향 값 | 분류 | 아이콘 |
| --- | --- | --- |
| -8 이하 | 현실주의자 | 왼쪽으로 크게 기울어진 진한 주홍색 |
| -7 ~ -4 | 현실주의자 | 왼쪽으로 약하게 기울어진 옅은 주홍색 |
| -3 ~ 3 | 중립 | 수평 회색 |
| 4 ~ 7 | 이상주의자 | 오른쪽으로 약하게 기울어진 옅은 청록색 |
| 8 이상 | 이상주의자 | 오른쪽으로 크게 기울어진 진한 청록색 |

분류 기준 ±4는 요청 사항이다. 강한 기울기 기준 ±8은 별도 지정이 없어 적용한 기본값이다.
`TendencyRules.StrongThreshold`에서 조절할 수 있다. 성향 수치는 제한하거나 변환하지 않는다.

## 적용 위치와 갱신

- GameWindow 상단 StateUI의 기존 `GoodAndDevil_Text` 영역을 활용한다.
- UIManager 초기화 시 PlayerTendencyUI를 연결한다. 씬 파일을 재저장하지 않고 실행 시 아이콘을 생성한다.
- 저울은 72×72, 오른쪽 한글 이름은 기존 폰트의 26 크기로 표시한다.
- Player.TendencyChanged에 반응하여 교체하며 매 프레임 성향을 검사하지 않는다.
- 초기 연결, 성향 변경·리셋, 기존 Player에 데이터 재로드, 플레이어 교체, UI 재활성화를 처리한다.
- Player 초기화 완료 시에도 TendencyChanged를 발행하도록 보완했다.
- 아이콘과 이름은 클릭을 가로채지 않는다.

## 변경 파일

- `TendencyRules.cs`: 숫자를 3가지 분류와 5가지 시각 단계로 해석하는 공통 규칙.
- `PlayerTendencyUI.cs`: 아이콘 로딩·캐시, 한글 이름, 이벤트 구독·해제.
- `UIManager.cs`: 기존 성향 표시 자리 및 현재 플레이어 연결.
- `Player.cs`: 데이터 초기화 완료 후 성향 갱신 알림.
- `PlayerTendencyValidation.cs`: 임포트 설정과 Edit Mode 검증.

PlayerData·SaveManager·Node/Item/Character SO·스프레드시트 양식은 변경하지 않았다.
기존 선택지 및 엔딩의 숫자 조건은 자동으로 바꾸지 않는다. 신규 분류 조건을 사용할 때 현실주의자 `<= -4`, 이상주의자 `>= 4`, 중립 `-3..3`으로 지정하면 된다.

## 검증 결과

- Unity 2021.3.45f2 Edit Mode 검사 40개 통과.
- ±4/±8 경계, 중립 범위, 정수 최솟값·최댓값, 5개 이미지 매핑·크기·필터 확인.
- 변경·리셋·로드·플레이어 교체·구독 해제·재활성화·중복 생성 방지 확인.
- 격리된 미리보기 씬에서 실제 게임 폰트로 5단계 UI를 렌더링해 글자와 아이콘이 겹치지 않는 것을 확인.
- Unity Console 오류 0개. VS/Unity 메시징 UDP 포트 경고 1개는 별도로 남아 있다.
- Play Mode와 모바일 실기기 검증은 수행하지 않았다. 실제 저장 파일 및 사용자 씬은 저장하지 않았다.

재검사 메뉴: `Tools > Validation > Player Tendency`
