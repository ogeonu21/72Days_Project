## 문서 추가 규칙

- 지속적으로 참고하는 안내는 Docs에, 작업별 기록은 Docs/AI에 작성한다.
- 작업 기록은 `기능-작업내용-YYYYMMDD.md`처럼 작성한다.
- 새 문서를 추가하면 이 목록의 해당 기능에 링크를 추가한다.
- 과거 기록을 최신 기능 설명으로 덮어쓰지 말고, 변경된 내용은 새 기록에서 설명한다.
- 문서는 UTF-8을 사용하고 비밀 키·서명 자료는 포함하지 않는다.
